# Bysan Style Controller

用于独立提供 Bysan 基础主题和学术内容样式，不依赖外部 Obsidian 主题或 Style Settings。

## 功能

- 统一控制浅色、深色模式下的代码块、行内代码、表格、引用块和列表标记配色。
- 控制代码块背景透明度、行号、换行、字间距与内置代码高亮主题。
- 控制表格斑马纹和默认居中样式。
- 控制内置基础主题的浅色、深色工作区背景。
- 在主题明暗切换时自动应用对应调色板。
- 独立接管编辑视图的活动代码行背景，不依赖 Style Settings 的 body class。
- 默认浅色代码背景和表格斑马纹经过可辨识度校准，避免“变量已生效但肉眼近似白色”。
- 内置经 MIT 许可打包的 Blue Topaz 基础 CSS，并由 Bysan 覆盖层统一控制最终效果。
- 将基础主题原有的 478 个实际设置项全部转为插件原生控件，包括工作区、文件树、标签页、编辑器、标题、列表、链接、Canvas、PDF、第三方插件适配等类别。
- 支持 140 类开关、51 类样式选择、浅色/深色独立颜色与透明度、数值滑杆、CSS 文本变量和设置搜索。
- 原主题标记为命令的 5 个开关也可从 Obsidian 命令面板调用。
- Live Preview 将 Mermaid、公式或嵌入内容的多行源码折叠为渲染块时，行号显示对应源行范围（如 `6–51`），避免被误认为漏号；可在设置中关闭。
- 支持命名保存、载入、覆盖和删除整套风格预设；每个预设同时包含浅色与深色配色、工作区、代码块、表格及完整主题控件。
- 内置不可删除的 “Bysan 默认（浅色/深色自适应）” 风格；恢复默认不会删除已保存的自定义风格。
- 当前风格存在未保存修改时，切换预设或恢复默认会打开确认弹窗，明确提供“取消”“舍弃修改并切换”“保存后切换”；未命名的当前设置可在弹窗中命名后保存。
- 自定义风格支持原地重命名；重命名只改变显示名称，不改变预设 ID 或任何样式内容。
- 插件的保存等关键操作按钮使用独立保护色，即使主题预设将全局强调色设为透明也保持可见。
- 设置页提供置顶功能导航，可直接跳转到风格预设、工作区、代码块、双模式配色、表格与引用，以及完整主题内部的整体、细节、插件适配和内置样式区域；主题搜索框已集成到导航表面，不再与导航形成两个重叠的置顶层。
- 设置界面不再显示打包主题遗留的社区群、赞助或仓库宣传项；第三方许可与必要署名仍保留在许可文件中。
- 插件界面语言默认跟随 Obsidian，也可固定为中文或 English；插件自有界面与完整主题控件会一起切换语言，中文模式不再用英文说明作为回退。
- 功能导航按“核心样式”和“完整主题”分组，并提供覆盖二至四级标题的细分区域选择器；内容中的一至四级区域也使用不同边框、底色和间距显示层级。
- 重复的浅色、深色配色区已合并为“双模式配色”，每项在同一行并列显示浅色与深色控件；工作区背景方案也采用同一行双模式设置，减少重复滚动。
- 每个颜色控件都提供独立恢复按钮：常用双模式配色恢复 Bysan 初始值，完整主题颜色则清除当前明暗模式的覆盖值并重新使用基础主题默认值，不影响另一模式。
- 拖动颜色时只刷新当前调色板或单个主题变量，不再重复重载 478 项主题设置或切换全局类。
- 主窗口使用稳定的不透明底层画布承接透明内容和背景图，设置导航取消毛玻璃合成层与闪烁动画，降低窗口移动、鼠标操作和滚动时的合成闪烁。
- 折叠源码行号采用差异更新；滚动时只处理发生变化的虚拟行号节点，不再清空并重建整页标记。

## 兼容边界

插件只接管视觉样式，不处理以下功能：

- 标题编号：继续由 `Academic Heading Numbering` 负责。
- 公式编号：继续由现有公式插件和 MathJax 负责。
- Mermaid、图片、表格宽度：继续由 `Mermaid Inline Resizer` 负责。
- 文字选择工具栏：继续由 `Selection Review Toolbar` 负责。

`Style Settings` 和外部 `Blue Topaz` 主题均不是依赖，可以安全卸载。基础样式始终由插件加载；所有可配置功能在插件设置中分别暴露，不再使用笼统的“内置基础主题”总开关。

未被用户修改的主题变量不会写入 `body` 行内样式；元数据中的透明占位色仅用于设置界面展示，不会覆盖基础主题的正文、公式或界面颜色。

## 安装

1. 将 `bysan-style-controller` 目录复制到 Vault 的 `.obsidian/plugins/`。
2. 在 Obsidian 的“第三方插件”中启用 **Bysan Style Controller**。
3. 如果此前启用了 `bysan-content-adapter.css`，请在“外观 → CSS 代码片段”中关闭它，避免同一套规则重复加载。
4. 在插件设置页调整配色和组件样式。
