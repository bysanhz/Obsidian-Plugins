# Bysan Style Controller

用于独立提供 Bysan 基础主题和学术内容样式，不依赖外部 Obsidian 主题或 Style Settings。

## 功能

- 统一控制浅色、深色模式下的代码块、行内代码、表格、引用块和列表标记配色。
- 将学术标题编号、Mermaid/图片/表格缩放和选区审阅工具栏作为三个可独立开关的内置模块统一管理；启用内置模块时会自动停用对应旧插件并迁移原数据，避免重复注册。
- 选区审阅工具栏在阅读模式下也会显示已有评论角标；点击角标可直接编辑、删除评论，对普通段落、标题和列表中可唯一定位的文字可新增评论。
- 评论角标默认缩小为 17px，并可在“功能模块 → 选区审阅工具栏”下用滑杆调整和一键恢复。
- 内置右侧“文档评论”导航面板，按当前文档列出评论、源文件行号、锚点和 Markdown/LaTeX 预览；点击卡片会跳回对应位置并打开评论窗。
- 控制代码块背景透明度、行号、换行、字间距与内置代码高亮主题。
- 控制表格斑马纹和默认居中样式。
- 控制内置基础主题的浅色、深色工作区背景。
- 在主题明暗切换时自动应用对应调色板。
- 独立接管编辑视图的活动代码行背景，不依赖 Style Settings 的 body class。
- 默认浅色代码背景和表格斑马纹经过可辨识度校准，避免“变量已生效但肉眼近似白色”。
- 内置经 MIT 许可打包的 Blue Topaz 基础 CSS，并由 Bysan 覆盖层统一控制最终效果。
- 将基础主题目录中的高级设置全部转为插件原生控件；475 项按界面位置自动归区，代码字号、粗体字重、Mermaid 缩放等重复项由更清晰的 Bysan 专用控件统一接管。
- 支持 140 类开关、51 类样式选择、浅色/深色独立颜色与透明度、数值滑杆、CSS 文本变量和设置搜索。
- 原主题标记为命令的 5 个开关也可从 Obsidian 命令面板调用。
- Live Preview 将 Mermaid、公式或嵌入内容的多行源码折叠为渲染块时，行号显示对应源行范围（如 `6–51`），避免被误认为漏号；可在设置中关闭。
- 支持命名保存、载入、覆盖和删除整套风格预设；每个预设同时包含浅色与深色配色以及所有界面区域的设置。
- 内置不可删除的 “Bysan 默认（浅色/深色自适应）” 风格；恢复默认不会删除已保存的自定义风格。
- 当前风格存在未保存修改时，切换预设或恢复默认会打开确认弹窗，明确提供“取消”“舍弃修改并切换”“保存后切换”；未命名的当前设置可在弹窗中命名后保存。
- 自定义风格支持原地重命名；重命名只改变显示名称，不改变预设 ID 或任何样式内容。
- 插件的保存等关键操作按钮使用独立保护色，即使主题预设将全局强调色设为透明也保持可见。
- 设置页提供置顶搜索与“功能与风格 / 工作区与界面 / 内容与阅读 / 插件与文档样式”四大分区导航；“完整主题”独立入口已取消，搜索覆盖全部设置并支持点击或 Enter 跨分区定位、自动展开和高亮目标。
- 每次只显示当前大分区，内部再用可折叠小区域、局部控件组和主题目录分层，避免依赖长页面连续滚动。
- 相关文字样式、字号、颜色和形态控制在同一局部网格内展示，但仍保持逐项独立修改；完整说明保留在控件提示中，卡片正文只显示三行摘要。
- 设置界面不再显示打包主题遗留的社区群、赞助或仓库宣传项；第三方许可与必要署名仍保留在许可文件中。
- 插件界面语言默认跟随 Obsidian，也可固定为中文或 English；全部区域控件会一起切换语言，中文模式不再用英文说明作为回退。
- 原主题目录按实际作用位置重新分配到整体工作区、顶部区、左侧区、右侧区、设置与系统界面、主编辑区、Canvas/图谱/PDF、第三方插件适配及文档样式类，原有设置 ID 和预设数据保持兼容。
- 内容设置以主编辑区为位置层级，再按代码块、行内代码、表格、引用块、文字与列表细分。每个对象内部集中放置功能、明暗外观、文字、尺寸和间距，不再设置独立的“双模式配色”区域。
- 每项明暗配色仍在同一行并列显示浅色与深色控件；工作区背景方案也采用同一行双模式设置，减少重复滚动。
- 同一背景的颜色与透明度合并为一张双模式组合卡，十六进制 RGBA 值、透明度数值、滑杆和恢复按钮集中呈现。
- 每个颜色控件都提供独立恢复按钮：主编辑区各对象的配色恢复 Bysan 初始值，高级区域颜色则清除当前明暗模式的覆盖值并重新使用基础主题默认值，不影响另一模式。
- 未保存覆盖值时，各区域面板会解析插件基础 CSS 与 Obsidian 当前样式，显示实际生效的浅色/深色颜色、透明度、数值和滑杆位置；颜色旁同时显示十六进制值，不再把透明占位元数据误当成真实默认值。
- 每个高级控件的说明都明确列出作用区域、真实默认值和 CSS/类标识；继承项会标明继承 Obsidian 或当前主题，便于从设置面板判断控件对应的界面位置。
- 代码块、行内代码、表格、引用、列表、任务框、分隔线及粗体的尺寸与间距已暴露为可复位滑杆，面板显示真实数值和单位。
- 拖动颜色时只刷新当前调色板或单个主题变量，不再重复重载 478 项主题设置或切换全局类。
- 主窗口使用稳定的不透明底层画布承接透明内容和背景图，设置导航取消毛玻璃合成层与闪烁动画，降低窗口移动、鼠标操作和滚动时的合成闪烁。
- 折叠源码行号采用差异更新；滚动时只处理发生变化的虚拟行号节点，不再清空并重建整页标记。
- 内置 PDF 分页预览与直接导出：预览和最终 PDF 共用同一份分页 DOM；纸张、方向、四边自定义页边距、实际缩放、页眉、页脚、页码、输出页面范围及黑白输出会直接进入导出，不再经过第二套打印设置；导出时可自行选择保存目录和文件名。
- PDF 预览缩放只改变左侧画布显示，实际缩放会重新参与内容排版与分页，避免文字或图表越出纸张；左侧支持双向滚动、页码跳转和箭头翻页，后台重新分页也会保留当前滚动位置。
- Mermaid 节点文字在分页预览阶段固定为居中的 SVG 文本，最终 PDF 直接复用同一 DOM，避免导出窗口字体度量变化造成文字右移或越框。

## 功能边界

- 标题编号、媒体缩放和文字选择工具栏已内置为互相隔离的功能模块，可在“功能模块”中单独启停。
- 阅读模式新增评论只自动处理可唯一映射回 Markdown 源文的普通文本；代码块、表格、Mermaid、公式和嵌入内容会提示切回编辑模式处理，避免误改源文。
- 公式编号仍由现有公式插件和 MathJax 负责，Style Controller 不修改公式编号逻辑。
- 仓库中原来的三个独立插件目录作为兼容回退保留；内置模块启用时会自动停用对应独立插件，因此不会同时运行两份实现。

`Style Settings` 和外部 `Blue Topaz` 主题均不是依赖，可以安全卸载。基础样式始终由插件加载；所有可配置功能在插件设置中分别暴露，不再使用笼统的“内置基础主题”总开关。

未被用户修改的主题变量不会写入 `body` 行内样式；元数据中的透明占位色不会覆盖基础主题的正文、公式或界面颜色，设置面板会改为展示其最终计算值。

## 自检

在仓库根目录运行 `node tests/style-controller-audit.js`，可审计界面区域归属、明暗调色板、默认值范围、透明占位来源、预设/导航/PDF 功能入口及中英文翻译完整性。

## 安装

1. 将 `bysan-style-controller` 目录复制到 Vault 的 `.obsidian/plugins/`。
2. 在 Obsidian 的“第三方插件”中启用 **Bysan Style Controller**。
3. 如果此前启用了 `bysan-content-adapter.css`，请在“外观 → CSS 代码片段”中关闭它，避免同一套规则重复加载。
4. 在插件设置页调整配色和组件样式。
