# Bysan Style Controller

用于独立提供 Bysan 基础主题和学术内容样式，不依赖外部 Obsidian 主题或 Style Settings。

## 功能

- 统一控制浅色、深色模式下的代码块、行内代码、表格、引用块和列表标记配色。
- 将学术标题编号、Mermaid/图片/表格缩放和选区审阅工具栏作为三个可独立开关的内置模块统一管理；启用内置模块时会自动停用对应旧插件并迁移原数据，避免重复注册。
- 选区审阅工具栏在阅读模式下也会显示已有评论角标；点击角标可直接编辑、删除评论，对普通段落、标题和列表中可唯一定位的文字可新增评论。
- 选中文字后点选区工具栏的「⋯」：编辑和阅读模式都能「复制原文引用」，生成 Markdown 引用和源笔记链接；能唯一定位时链接会指向所在标题。编辑模式还可「插入链接」，搜索库内笔记或粘贴完整 HTTP(S) 网址，以当前选中文字作为链接名。插入链接支持一次撤销；不会自动打开目标网页。
- 评论角标默认大小为 17px，可在「工具与预设 → 功能开关」中调整和恢复。
- 内置右侧“文档评论”导航面板，按当前文档列出评论、源文件行号、锚点和 Markdown/LaTeX 预览；点击卡片会跳回对应位置并打开评论窗。
- 控制代码块背景透明度、行号、换行、字间距与内置代码高亮主题。
- 控制表格斑马纹和默认居中样式。
- 控制内置基础主题的浅色、深色工作区背景。
- 在主题明暗切换时自动应用对应调色板。
- 独立接管编辑视图的活动代码行背景，不依赖 Style Settings 的 body class。
- 默认浅色代码背景和表格斑马纹经过可辨识度校准，避免“变量已生效但肉眼近似白色”。
- 内置经 MIT 许可打包的 Blue Topaz 基础 CSS，并由 Bysan 覆盖层统一控制最终效果。
- 将基础主题目录中的设置转为插件原生控件，按实际用途归区；代码字号、粗体字重、Mermaid 缩放等重复项由 Bysan 专用控件统一接管。
- 支持 140 类开关、51 类样式选择、浅色/深色独立颜色与透明度、数值步进控件、CSS 文本变量和设置搜索。
- 原主题标记为命令的 5 个开关也可从 Obsidian 命令面板调用。
- Live Preview 将 Mermaid、公式或嵌入内容的多行源码折叠为渲染块时，行号显示对应源行范围（如 `6–51`），避免被误认为漏号；可在设置中关闭。
- 支持命名保存、载入、覆盖和删除整套风格预设；每个预设同时包含浅色与深色配色以及所有界面区域的设置。
- 内置不可删除的 “Bysan 默认（浅色/深色自适应）” 风格；恢复默认不会删除已保存的自定义风格。
- 当前风格存在未保存修改时，切换预设或恢复默认会打开确认弹窗，明确提供“取消”“舍弃修改并切换”“保存后切换”；未命名的当前设置可在弹窗中命名后保存。
- 自定义风格支持原地重命名；重命名只改变显示名称，不改变预设 ID 或任何样式内容。
- 插件的保存等关键操作按钮使用独立保护色，即使主题预设将全局强调色设为透明也保持可见。
- 设置页只有「笔记样式」「界面样式」「工具与预设」三个入口，不再另分高级设置。正文、标题、代码、表格和引用各有阅读样例，随当前明暗模式和设置更新。
- 「工具与预设」集中管理标题编号、媒体缩放、评论、空行清理、PDF 和风格预设。PDF 的版式与输出范围在预览窗口调整。
- 顶部的「跳到分组」用于在当前页面快速定位。搜索覆盖全部设置，点击结果或按 Enter 可跨页定位，原设置 ID 和已保存的风格保持兼容。
- 设置页构建期间暂停面板排版，构建完成后立即恢复显示，减少打开时的卡顿；三个区域的设置仍可直接搜索。
- 相关文字样式、字号、颜色和形态控制在同一局部网格内展示，但仍保持逐项独立修改；完整说明保留在控件提示中，卡片正文只显示三行摘要。
- 设置界面不再显示打包主题遗留的社区群、赞助或仓库宣传项；第三方许可与必要署名仍保留在许可文件中。
- 插件界面语言默认跟随 Obsidian，也可固定为中文或 English；全部区域控件会一起切换语言，中文模式不再用英文说明作为回退。
- 原主题目录按实际作用位置重新分配到整体工作区、顶部区、左侧区、右侧区、设置与系统界面、主编辑区、Canvas/图谱/PDF、第三方插件适配及文档样式类，原有设置 ID 和预设数据保持兼容。
- 页面标题和 H1–H6 使用同一个级别选择器。选定级别后，其颜色、字号、背景和下划线都在同一个样例旁；全局搜索也能直接切到相应级别。
- 表格、引用块、提示框、代码、公式与列表的样例使用 Obsidian 的 Markdown 渲染器。相关外观选项归在各自样例旁，文件树底色、图片及透明度也放到文件树样例旁。
- 「代码」内可分别为代码块和行内代码选择常用等宽字体、跟随 Obsidian 或输入自定义字体；未选时沿用原配置。行内代码边框支持独立的浅色、深色与透明度，恢复后跟随代码块边框。
- 字体、字重、字形、下划线线型和列表标记等样式使用下拉框。字体下拉框用对应字体显示名称，下方预览「中文 日本語 English」，并支持中文名、英文名及别名搜索。仍可沿用默认、跟随 Obsidian，或手动输入备用字体列表。读取系统字体失败时显示常用字体作为备选。
- 正文、标题、代码、表格、引用和块公式等字号按排版点数（pt，磅）显示。用「− / +」、方向键或直接输入数值，按回车应用，点「↺」恢复。旧字号不自动改写；未自定义时仍沿用原来的相对字号或主题默认值。
- 「笔记背景」只用一个「笔记底色」控件。未设新色时，仍显示对应纹理在旧预设中的底色；编辑底色不会移除纹理，按浅色或深色恢复只清除该模式的笔记底色。背景图是独立的底层，可透过透明的笔记底色显示。预览与编辑、阅读视图共用图层样式。
- 「界面样式 → 界面颜色」包含左栏、右栏、当前标签、文件树当前文件、状态栏和界面强调色。重置独立颜色后重新使用原来的主题颜色。
- 每项明暗配色仍在同一行并列显示浅色与深色控件；工作区背景方案也采用同一行双模式设置，减少重复滚动。
- 同一背景的颜色与透明度同排显示，仅保留色块、透明度和恢复按钮。十六进制色值可悬停色块查看；窄窗口自动换行。
- 名称与说明在各自区域内换行，不覆盖色块和数值控件。选项名省去来源后缀，相关署名仍在许可文件中。
- 标签预览分为「笔记中实际显示」和「彩色方案（未启用）」。选择「标签样式 → 自定义彩色标签」后，颜色 1–5 才会应用到笔记，预览也会合为一行。
- 「选区、高亮与链接」的彩色高亮和答案遮挡按写法分组，样例与相应的配色、线型一起显示。复习时可用 `==~~答案~~==`（悬停看答案）、`*==~~答案~~==*`（按住鼠标看答案）或 `*~~答案~~*`（留空，悬停看答案）。关闭全局开关只恢复普通格式，不会改写笔记。
- 「页面标题与文内标题 → 标题编号（所有级别）」可独立调节编号的浅色/深色颜色与间距，应用于编辑、阅读、大纲和 PDF。编号逻辑和标题文字样式不变。
- 「工具与预设 → 功能开关 → 文档评论面板配色」支持单独调整面板、标题、空状态提示框和卡片配色。没有面板底色覆盖时，跟随自定义的右侧栏背景；如果两者都未设置，保留原评论面板配色。
- 图片嵌入、标签页、文件树、大纲、菜单、白板和图谱也提供就地样例；窗口、白板和图谱样例用于对照颜色，并非完整视图。
- 颜色恢复按钮只还原对应控件和明暗模式，不影响另一模式。
- 「列表、任务与分隔线」将列表符号与层级线分组；无序列表可选默认、自动彩色或逐层自定义。自动配色可调基础色，阅读模式仅在选择渐变后显示渐变色。四级列表样例可切换编辑实时预览与阅读样式，不改当前笔记。
- 笔记样例与阅读视图共用正文结构和主题样式，包括首行缩进、段落间距、笔记底色和纸张纹理；样例栏宽不同，换行位置可能不同。「对照当前笔记」会显示原来的笔记和模式，独立设置窗口可保持打开并与笔记并排查看。界面、编辑选区及列表编辑的模拟样例标为「示意」。若设置内嵌在主窗口，可用命令「打开样式设置」返回。
- 未保存覆盖值时，各区域面板会解析插件基础 CSS 与 Obsidian 当前样式，显示实际生效的浅色/深色颜色、透明度和数值，不再把透明占位元数据误当成真实默认值。
- 基础主题控件的说明列出作用区域、真实默认值和 CSS/类标识；继承项会标明继承 Obsidian 或当前主题。
- 尺寸、间距、透明度和 PDF 缩放、页边距统一使用「− / 数值 / + / 单位 / 恢复」控件。原有滑条保留，并与步进输入和恢复操作同步。无单位的比例不额外显示单位；明暗配色的恢复按钮仍只影响对应模式。旧设置值和 CSS 单位不迁移，已有的 CSS 表达式照常保留，也可直接编辑。
- 拖动颜色时只刷新当前调色板或单个主题变量，不再重复重载 478 项主题设置或切换全局类。
- 主窗口使用稳定的不透明底层画布承接透明内容和背景图，设置导航取消毛玻璃合成层与闪烁动画，降低窗口移动、鼠标操作和滚动时的合成闪烁。
- 折叠源码行号采用差异更新；滚动时只处理发生变化的虚拟行号节点，不再清空并重建整页标记。
- 内置 PDF 分页预览与直接导出：预览和最终 PDF 共用同一份分页 DOM；纸张、方向、四边自定义页边距、实际缩放、页眉、页脚、页码、输出页面范围及黑白输出会直接进入导出，不再经过第二套打印设置；导出时可自行选择保存目录和文件名。
- PDF 预览缩放只改变左侧画布显示，实际缩放会重新参与内容排版与分页，避免文字或图表越出纸张；左侧支持双向滚动、页码跳转和箭头翻页，后台重新分页也会保留当前滚动位置。
- Mermaid 节点文字在交互预览中保持 Obsidian 原生渲染；仅在最终导出时以同一份已分页 DOM 转换为居中的 SVG 文本，避免导出窗口字体度量变化造成文字右移或越框，也避免长文档每次预览刷新重复转换全部图表。
- 导出会冻结预览页当前已计算的主题变量、字体和颜色，并启用精确打印颜色，避免独立导出窗口重新解析主题后与预览出现背景或文字配色差异。
- 长文档渲染不再观察每个 Mermaid/MathJax 的后台 DOM 变动，因此不会反复清空并重启分页；实际的文档编辑、版式设置或图片加载才会触发重分页。

## 功能边界

- 标题编号、媒体缩放和文字选择工具栏已内置为互相隔离的功能模块，可在「工具与预设」中单独启停。
- 阅读模式新增评论只自动处理可唯一映射回 Markdown 源文的普通文本；代码块、表格、Mermaid、公式和嵌入内容会提示切回编辑模式处理，避免误改源文。
- 公式编号仍由现有公式插件和 MathJax 负责，Style Controller 不修改公式编号逻辑。
- 仓库中原来的三个独立插件目录作为兼容回退保留；内置模块启用时会自动停用对应独立插件，因此不会同时运行两份实现。

`Style Settings` 和外部 `Blue Topaz` 主题均不是依赖，可以安全卸载。基础样式始终由插件加载；所有可配置功能在插件设置中分别暴露，不再使用笼统的“内置基础主题”总开关。

未被用户修改的主题变量不会写入 `body` 行内样式；元数据中的透明占位色不会覆盖基础主题的正文、公式或界面颜色，设置面板会改为展示其最终计算值。

## 自检

在仓库根目录运行 `node tests/style-controller-audit.js`，可审计界面区域归属、明暗调色板、默认值范围、透明占位来源、预设/导航/PDF 功能入口及中英文翻译完整性。

## 安装

1. 将 `bysan-style-controller` 目录复制到 Vault 的 `.obsidian/plugins/`。
2. 在 Obsidian 的“第三方插件”中启用 **Bysan Style Controller**。
3. 如果此前启用了 `bysan-content-adapter.css`，请在“外观 → CSS 代码片段”中关闭它，避免同一套规则重复加载。
4. 在插件设置页调整配色和组件样式。

# 空行清理分类设置（0.16.9）

在「工具与预设 → 空行清理」设置各类型的保留规则。开启表示保留前后一行，关闭表示清理。相邻任一类型要求保留即保留。默认保留独立模块周围空行，清理普通文字周围空行。可批量开启清理或恢复默认。

侧边栏清理按钮仍需确认，支持一次撤回。模块内部空行及避免 Setext 意外标题的空行始终保护。清理设置不随风格预设切换。
